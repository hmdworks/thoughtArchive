# thoughtArchive

<i>a place to write and recall your thoughts.</i>

<br>

run `ta add my thought` or `ta add my thought 11-11 11:11`

to add a thought to the Archive.

to view,

run `ta view` for 20 or `ta view N` for N recent thoughts.

`ta ls` gives a list of thoughts for the current archive day (until 5am).

<br>
